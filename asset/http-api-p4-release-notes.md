# HTTP API 0.4.0-p4

完整上传/下载、目录与空文件、策略/重试、实例并发与限速、真实暂停/恢复、暂存引用及内容代理已交付；DWN05短期票据作为独立扩展交付。当前51 implemented、0 partial、54 planned。

旧P2请求的幂等身份与检查点绑定保持；普通凭据更新绑定旧版本、显式撤销和未知提交语义保持。schema v5为加法迁移，升级前停机一致备份配套密钥、DB和内容目录；回滚恢复升级前备份。上传128GiB代码上限、暂存256MiB单文件/1GiB总量、目录计划10000项、16文件/32线程/256总线程为明确边界，未声称这些最大规模均通过真实百度测试。

使用、完整验收及离线/上游范围分别见[P4指南](http-api-p4-guide.md)、[P4验收](http-api-p4-verification.md)和[脱敏上游报告](http-api-p4-upstream-verification.json)。P5网盘写业务继续开发；P0已知旧测试问题保持单列。
